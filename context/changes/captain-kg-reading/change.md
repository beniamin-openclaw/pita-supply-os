## Notes

— read-only kg reading next to the Captain's stock count for piece-counted products whose name carries a weight (halloumi 200gr: "12 szt (2,4 kg)"); porzadek-2026-10 item 4.14

Background (Ben, 17.10): Kraków's 11.10 report asked for halloumi in kg. Only cut halloumi is
counted in kg (P192 "Halloumi cięte", count-only, already live). Ordered halloumi stays in pieces
(P015, 200 g each); after the count is typed the screen shows in brackets how many kg that is.
D8/W49 stays: one inventory unit per product. Display only — the stored value stays in inventory
units; no API, backend or prod change.
